# SETUP GUIDE FOR TEAMMATES
# ──────────────────────────
# 1. Create a virtual environment:
#      python -m venv venv
#      venv\Scripts\activate        # Windows
#      source venv/bin/activate     # Mac/Linux
#
# 2. Install dependencies:
#      pip install -r requirements.txt
#
# 3. Install Ollama (local AI runtime — NOT in pip, must install separately):
#      Windows : winget install Ollama.Ollama
#      Mac     : brew install ollama
#      Linux   : curl -fsSL https://ollama.com/install.sh | sh
#
# 4. Pull the two required AI models (one-time, ~2.3 GB total):
#      ollama pull llama3.2:3b        # Chat LLM (~2 GB)
#      ollama pull nomic-embed-text   # Embeddings (~274 MB)
#
# 5. Copy .env.example → .env and fill in your values.
#
# 6. Seed the local knowledge base (first time only):
#      python -m ai.seed_knowledge
