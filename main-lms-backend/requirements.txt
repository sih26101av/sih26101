# SETUP GUIDE FOR TEAMMATES
# ──────────────────────────
# 1. Create a virtual environment:
#      python -m venv venv
#      venv\Scripts\activate        # Windows
#      source venv/bin/activate     # Mac/Linux
#
# 2. Install dependencies:
#      pip install -r requirements.txt
#
#    Two embedding models (~560 MB disk total) download from HuggingFace Hub
#    on first run and are cached locally — see ai/embedder.py. No API key.
#
# 3. (OPTIONAL — local dev only) Install Ollama for Tier 3 RAG:
#      Windows : winget install Ollama.Ollama
#      Mac     : brew install ollama
#      Linux   : curl -fsSL https://ollama.com/install.sh | sh
#
# 4. (OPTIONAL) Pull Ollama models (~2.3 GB total):
#      ollama pull llama3.2:3b        # Chat LLM (~2 GB)
#      ollama pull nomic-embed-text   # Embeddings (~274 MB)
#
# 5. Copy .env.example → .env and fill in your values.
#
# 6. (OPTIONAL) Seed local knowledge base:
#      python -m ai.seed_knowledge
